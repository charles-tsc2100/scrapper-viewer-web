Overview
ภาพรวม

BOQ to Warehouse Form Converter

โปรแกรมแปลง BOQ เป็นแบบฟอร์มคลังสินค้า

Automatically extract door types, hardware products, and quantities from BOQ Excel files and generate clean warehouse picking forms — ready for your team in seconds.

แปลงไฟล์ BOQ Excel ให้เป็นแบบฟอร์มเบิกสินค้าคลังสินค้าโดยอัตโนมัติ ดึงข้อมูลประเภทประตู อุปกรณ์ และจำนวนได้อย่างรวดเร็วและแม่นยำ

ℹ️ This app is designed for Today Style 2100 Co., Ltd. and is optimized for Thai construction hardware BOQ documents structured with a cover sheet (ใบปะหน้า) and BOQ sheets. โปรแกรมนี้ออกแบบมาสำหรับ บริษัท Today Style 2100 และเหมาะสำหรับเอกสาร BOQ อุปกรณ์ก่อสร้างของไทย ที่มีโครงสร้างประกอบด้วยใบปะหน้าและชีท BOQ

BOQ File Requirements

  • รูปแบบ: .xlsx (Excel)
  • Must contain a ใบปะหน้า cover sheet
  • ต้องมีชีท ใบปะหน้า

⚠️ BOQ files must include the "ใบปะหน้า" (cover sheet) for door quantity mapping to work correctly. Without it, the app cannot match how many of each door type are needed. ไฟล์ BOQ ต้องมีชีท "ใบปะหน้า" เพื่อให้การแมปจำนวนประตูทำงานได้ถูกต้อง หากไม่มี โปรแกรมจะไม่สามารถระบุจำนวนของแต่ละประเภทประตูได้

Sheet Naming Conventions

รูปแบบการตั้งชื่อชีต

The converter supports two naming formats for BOQ sheets. You can use either one — the app auto-detects which format your file uses.

ตัวแปลงรองรับรูปแบบการตั้งชื่อ 2 แบบสำหรับชีต BOQ สามารถใช้แบบใดก็ได้ — แอปจะตรวจจับรูปแบบอัตโนมัติ

Option 1: Door Code Sheets แบบที่ 1: ตั้งชื่อชีตด้วยรหัสประตู

Each sheet is named after the door code directly. This is the straightforward approach.

แต่ละชีตตั้งชื่อตามรหัสประตูโดยตรง เป็นวิธีที่ตรงไปตรงมา

Sheet: D1 → door code D1
Sheet: D2 → door code D2
Sheet: AD1 → door code AD1
Sheet: D1,2,5,3 → D1, D2, D5, D3
Option 2: Group Sheets แบบที่ 2: ตั้งชื่อชีตด้วย Group

Sheets are named by group (e.g. Group1, Group2A). The actual door codes must be listed inside the sheet, under the group label.

ชีตตั้งชื่อตาม Group (เช่น Group1, Group2A) โดยรหัสประตูจริงต้องระบุอยู่ภายในชีต ใต้ชื่อ Group

Sheet: Group1 → contains D01, D09
Sheet: Group3,5 → Group 3 + Group 5
Sheet: Group22-AD01,03 → AD01, AD03
💡 Comma-separated names auto-split: Sheet names like D1,2,3 automatically expand into individual door codes (D1, D2, D3). Similarly, Group3,5 is treated as two groups (Group 3 and Group 5) with their door codes separated accordingly. Each door code inherits its group's quantity from the cover sheet. ชื่อที่คั่นด้วยจุลภาคจะแยกอัตโนมัติ: ชื่อชีตเช่น D1,2,3 จะขยายเป็นรหัสประตูแต่ละบานอัตโนมัติ (D1, D2, D3) เช่นเดียวกับ Group3,5 ที่จะถูกแยกเป็น 2 กลุ่ม (Group 3 และ Group 5) โดยรหัสประตูในแต่ละกลุ่มจะรับจำนวนจากใบปะหน้าตาม Group ที่สังกัด

Launching the App

วิธีเปิดโปรแกรม

🖱️

Option A — Executable (.exe)

วิธี A — ไฟล์ .exe

Double-click BOQ Converter.exe inside the dist/ folder. No installation needed.

ดับเบิลคลิกที่ BOQ Converter.exe ในโฟลเดอร์ dist/ ไม่จำเป็นต้องติดตั้งเพิ่มเติม

⌨️

Option B — run.bat

วิธี B — run.bat

Double-click run.bat in the BOQ Converter App/ folder. Python must be installed and in your PATH.

ดับเบิลคลิกที่ run.bat ในโฟลเดอร์ BOQ Converter App/ ต้องติดตั้ง Python ไว้ในระบบก่อน

Step 1
ขั้นตอนที่ 1

Load BOQ Files

โหลดไฟล์ BOQ

Select one or more BOQ Excel files to process.

เลือกไฟล์ BOQ Excel ตั้งแต่หนึ่งไฟล์ขึ้นไปเพื่อประมวลผล

1
Click "+ Add BOQ Files"
คลิก "+ เพิ่มไฟล์ BOQ"

A file browser dialog will open. Navigate to your BOQ Excel files and select one or more files at once (hold Ctrl for multi-select).

กล่องโต้ตอบเลือกไฟล์จะเปิดขึ้น ไปยังโฟลเดอร์ที่มีไฟล์ BOQ Excel แล้วเลือกไฟล์ได้ครั้งละหลายไฟล์ (กด Ctrl เพื่อเลือกหลายไฟล์)

2
Wait for auto-detection
รอการตรวจจับอัตโนมัติ

The app automatically reads your files and detects the column layout (door codes, product columns, pricing columns). The status bar shows "Parsing..." while this runs.

โปรแกรมจะอ่านไฟล์และตรวจจับเลย์เอาต์คอลัมน์โดยอัตโนมัติ (รหัสประตู คอลัมน์สินค้า คอลัมน์ราคา) แถบสถานะจะแสดง "กำลังประมวลผล..." ระหว่างนี้

💡 The config status will show "Auto-detected" if the app recognized your file structure, or "Using defaults" if it fell back to standard settings.
💡 สถานะการตั้งค่าจะแสดง "ตรวจพบอัตโนมัติ" หากโปรแกรมรู้จักโครงสร้างไฟล์ หรือ "ใช้ค่าเริ่มต้น" หากใช้การตั้งค่ามาตรฐาน
3
Review the file list
ตรวจสอบรายการไฟล์

Selected filenames appear in the file list box. The label above shows the file count. To remove all files, click Clear All.

ชื่อไฟล์ที่เลือกจะแสดงในกล่องรายการ ป้ายกำกับด้านบนจะแสดงจำนวนไฟล์ หากต้องการลบไฟล์ทั้งหมด ให้คลิก ล้างทั้งหมด

Step 2
ขั้นตอนที่ 2

Configure Settings

ปรับการตั้งค่า

Adjust the project name, pricing options, and cell reference mappings if needed.

ปรับชื่อโครงการ ตัวเลือกราคา และการแมปการอ้างอิงเซลล์ตามต้องการ

Project Name

ชื่อโครงการ

Type a project name in the text field. This name will appear as the title in the generated warehouse form. If left blank, the app uses the BOQ filename.

พิมพ์ชื่อโครงการในช่องข้อความ ชื่อนี้จะปรากฏเป็นหัวเรื่องในแบบฟอร์มคลังสินค้าที่สร้างขึ้น หากเว้นว่างไว้ โปรแกรมจะใช้ชื่อไฟล์ BOQ แทน

Pricing Options

ตัวเลือกราคา

Optionตัวเลือก Defaultค่าเริ่มต้น What it doesผลที่ได้
Include Pricingรวมราคา ONเปิด Adds NET price and discount columns to the output form. เพิ่มคอลัมน์ราคา NET และส่วนลดในแบบฟอร์มผลลัพธ์
Use UNIT Priceใช้ราคาต่อหน่วย OFFปิด When ON: uses raw Unit Price instead of the NET discounted price. เมื่อเปิด: ใช้ราคาต่อหน่วยดิบแทนราคา NET ที่มีส่วนลด
⚙️

Cell References (Advanced)

การอ้างอิงเซลล์ (ขั้นสูง)

Click "Cell References..." to open the configuration dialog. Use this only if auto-detection did not pick up the correct columns.

คลิก "อ้างอิงเซลล์..." เพื่อเปิดกล่องโต้ตอบการกำหนดค่า ใช้เฉพาะเมื่อการตรวจจับอัตโนมัติไม่ถูกต้อง

✅ Most of the time, auto-detection works correctly and you do not need to open this dialog. โดยส่วนใหญ่ การตรวจจับอัตโนมัติจะทำงานได้ถูกต้อง และไม่จำเป็นต้องเปิดกล่องโต้ตอบนี้
Step 3
ขั้นตอนที่ 3

Read the Preview

อ่านตัวอย่างผลลัพธ์

The preview panel confirms what the app found in your files before you convert.

แผงตัวอย่างยืนยันสิ่งที่โปรแกรมพบในไฟล์ของคุณก่อนการแปลง

A healthy preview will show:

ตัวอย่างที่ถูกต้องจะแสดง:

✓
Config status — "Auto-detected" or "Custom config"
สถานะการตั้งค่า — "ตรวจพบอัตโนมัติ" หรือ "กำหนดเอง"

Confirms which column layout was used.

ยืนยันว่าใช้เลย์เอาต์คอลัมน์ใด

✓
Product categories — e.g. MIWA, BEST, HAFELE
หมวดหมู่สินค้า — เช่น MIWA, BEST, HAFELE

Lists the brand/category groups found across all BOQ sheets.

แสดงรายการกลุ่มแบรนด์/หมวดหมู่ที่พบในชีท BOQ ทั้งหมด

✓
Door types — e.g. D1, D2, SD1
ประเภทประตู — เช่น D1, D2, SD1

All door codes found in both the BOQ sheets and the cover sheet.

รหัสประตูทั้งหมดที่พบในชีท BOQ และใบปะหน้า

✓
Quantity mapping — e.g. D1=5, D2=12
การแมปจำนวน — เช่น D1=5, D2=12

The number of each door type, pulled from the ใบปะหน้า cover sheet.

จำนวนของแต่ละประเภทประตู ดึงมาจากชีท ใบปะหน้า

🚨
If the preview shows errors or missing data: หากตัวอย่างแสดงข้อผิดพลาดหรือข้อมูลหายไป:
  • Verify the BOQ file includes a ใบปะหน้า sheet
  • ตรวจสอบว่าไฟล์ BOQ มีชีท ใบปะหน้า
  • Open Cell References... and verify column assignments
  • เปิด อ้างอิงเซลล์... และตรวจสอบการกำหนดคอลัมน์
  • Check the status bar at the bottom for a more detailed error message
  • ตรวจสอบแถบสถานะด้านล่างสำหรับข้อความแสดงข้อผิดพลาดโดยละเอียด
Step 4
ขั้นตอนที่ 4

Convert & Save

แปลงและบันทึก

Generate the warehouse picking form Excel file.

สร้างไฟล์ Excel แบบฟอร์มเบิกสินค้าคลังสินค้า

1
Click "Convert to Warehouse Form"
คลิก "แปลงเป็นแบบฟอร์มคลังสินค้า"

The large cyan button at the bottom right of the app. It will be enabled once files are loaded and parsed successfully.

ปุ่มสีฟ้าขนาดใหญ่ที่ด้านล่างขวาของโปรแกรม จะเปิดใช้งานได้เมื่อโหลดและประมวลผลไฟล์สำเร็จแล้ว

2
Choose a save location
เลือกที่บันทึกไฟล์

A "Save As" dialog opens. Navigate to your desired folder and enter a filename. The output file will be saved as .xlsx.

กล่องโต้ตอบ "บันทึกเป็น" จะเปิดขึ้น นำทางไปยังโฟลเดอร์ที่ต้องการและพิมพ์ชื่อไฟล์ ไฟล์ผลลัพธ์จะถูกบันทึกเป็น .xlsx

3
File opens automatically
ไฟล์เปิดโดยอัตโนมัติ

Once conversion is complete, the output Excel file will automatically open in Microsoft Excel. The status bar shows "Conversion complete!".

เมื่อการแปลงเสร็จสิ้น ไฟล์ Excel ผลลัพธ์จะเปิดขึ้นโดยอัตโนมัติใน Microsoft Excel แถบสถานะจะแสดง "การแปลงเสร็จสมบูรณ์!"

⚠️ If Excel is not installed, the file is still saved correctly — you just need to open it manually.
⚠️ หากไม่ได้ติดตั้ง Excel ไฟล์ยังคงถูกบันทึกอย่างถูกต้อง เพียงแต่ต้องเปิดด้วยตนเอง

Output File Structure

โครงสร้างไฟล์ผลลัพธ์

Row(s)แถว Contentเนื้อหา
1 Project name and generation date ชื่อโครงการและวันที่สร้าง
3 Column headers (Product, Price/NET, Door codes, Total) หัวคอลัมน์ (สินค้า, ราคา/NET, รหัสประตู, รวม)
4 Category label (e.g. MIWA, BEST) ป้ายหมวดหมู่ (เช่น MIWA, BEST)

Last rowsแถวสุดท้าย Totals and summary per door type ยอดรวมและสรุปต่อประเภทประตู
