FONTS FOR BOQ CONVERTER APP
============================

To get the full "Technical Curator" design, download these fonts and place the .ttf files in this folder:

1. Inter (body text):
   - Download from: https://fonts.google.com/specimen/Inter
   - Place: Inter-Regular.ttf, Inter-Bold.ttf (or Inter-VariableFont_opsz,wght.ttf)

2. Space Grotesk (headlines):
   - Download from: https://fonts.google.com/specimen/Space+Grotesk
   - Place: SpaceGrotesk-Regular.ttf, SpaceGrotesk-Bold.ttf (or SpaceGrotesk-VariableFont_wght.ttf)

The app will automatically detect and load these fonts on Windows.
If fonts are not present, Segoe UI is used as a fallback.
